# 01: Запустить KMP-приложение и импортировать подписку

Status: ready-for-agent
Completion: implemented; verification recorded below

**What to build:** пользователь запускает Android-приложение в эмуляторе, вставляет HTTPS Subscription URL, загружает список Connection profiles, выбирает сервер и видит сохранённый результат после перезапуска. Это настоящий импорт без имитации работающего VPN.

**Blocked by:** None (can start immediately).

**Parent:** [Android VPN MVP](../spec.md).

## Дизайн — прочитать перед UI

Следовать [design handoff](../../../docs/agents/design.md) и [Pencil-источнику](../../../design/xray-mobile.pen). Основные ориентиры: **Android · Profiles**, **Profile Row**, **Android Nav Bar**; для формы — адаптация **iOS · Import** к Subscription URL. Точные ID, доступ через Pencil CLI/MCP или computer use и правила адаптации находятся в handoff. Подготовить общую Compose-тему и компоненты для следующих задач.

## Контекст

Проект пока не содержит прикладного кода. Использовать Kotlin Multiplatform и общий Compose UI, Android первым; iOS отложен. Одна подписка, вставка в поле, ручные загрузка и обновление. Наблюдаемый ответ провайдера — Base64 со списком VLESS-ссылок: XHTTP/TLS и TCP/REALITY с xtls-rprx-vision. Не фиксировать количество профилей и не включать реальные параметры доступа в код.

## Acceptance criteria

- [x] Список, выбор, FAB и форма подписки следуют предоставленному дизайну и его MVP-адаптациям. Пустое состояние, загрузка и ошибка используют ту же визуальную систему; макет JSON-импорта не превращается в неподдерживаемую функцию.
- [x] Выполнена визуальная сверка в эмуляторе: приложены скриншоты без секретов и использованные фреймы, проверены длинные имена, клавиатура и доступность основных действий. Отклонения описаны по design handoff.
- [x] Проект имеет воспроизводимую сборку с зафиксированными совместимыми версиями и Gradle Wrapper; Android-приложение устанавливается и запускается на ARM64 AVD.
- [x] Общая модель и логика импорта находятся в KMP-части, не зависят от Android API; UI написан на Compose Multiplatform. Не требуется рабочая iOS-сборка.
- [x] Пользователь может вставить HTTPS URL, явно начать загрузку, увидеть прогресс, отменить её и повторить после ошибки.
- [x] Поддерживаются оба наблюдаемых семейства VLESS-профилей с сохранением значимых параметров транспорта и безопасности. Список имеет понятные названия и явный выбор сервера.
- [x] Повреждённые и неподдерживаемые записи не выбираются для подключения; пользователь видит информацию о пропусках. Отсутствие пригодных профилей является ошибкой.
- [x] Неправильная ссылка, ошибки HTTP/TLS, таймаут, превышение ограничения ответа и неверный формат дают понятную ошибку; проверка TLS не отключается.
- [x] Успешный импорт атомарно заменяет сохранённую подписку; ошибка или отмена сохраняет прежние данные. Обновление сохраняет выбор существующего профиля; если профиль исчез, нужен новый явный выбор.
- [x] Подписка, профили и выбор восстанавливаются после перезапуска из закрытого хранилища приложения. Секреты защищены от непреднамеренного резервного копирования и не выводятся в диагностику.
- [x] Импорт и запуск приложения не запускают VPN. До задачи 02 интерфейс не сообщает о настоящем подключении и не содержит вводящей в заблуждение работающей кнопки VPN.
- [x] Автотесты через команды и состояние приложения проверяют успешный импорт, ошибки, отмену, сохранение и восстановление; отдельные сложные случаи формата покрыты синтетическими примерами без личной подписки.
- [x] В эмуляторе продемонстрирован полный сценарий ввода, списка и сохранения; записаны команды сборки и тестов с результатами, без секретов.

## Проверка

Работать через согласованную границу команд приложения и наблюдаемого состояния, подменяя загрузчик и хранилище там, где это нужно для детерминированности. Добавить короткую инструкцию локального запуска для следующей задачи. Истинная готовность VPN здесь не проверяется и не заявляется.
