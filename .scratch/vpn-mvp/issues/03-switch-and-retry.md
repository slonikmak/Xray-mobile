# 03: Переключать сервер и вручную восстанавливать соединение

Status: ready-for-agent
Completion: implemented; verification recorded in evidence

**What to build:** пользователь меняет сервер в работающем VPN, получает понятную ошибку при неудаче и вручную повторяет подключение. Сворачивание приложения, обновление подписки и запоздалые события не искажают активную сессию.

**Blocked by:** 02 — Подключить настоящий VPN через Xray (включает результат 01).

**Parent:** [Android VPN MVP](../spec.md).

## Дизайн — прочитать перед UI

Следовать [design handoff](../../../docs/agents/design.md) и [Pencil-источнику](../../../design/xray-mobile.pen). Использовать **Android · Profiles**, оба **Android · Home** и общие компоненты предыдущих задач. Для переключения, ошибки и ручного Retry применить правила недостающих состояний из handoff; **Android · Diagnostics** является стилистическим ориентиром, а не требованием реализовать экспорт логов или новый экран.

## Контекст

Предыдущие задачи обеспечивают импорт подписки, выбор, сохранение, реальный VPN, остановку и Connection check. Пользователь подтвердил ручное восстановление через «Повторить», без автопереподключения. Должна существовать не более чем одна активная VPN-сессия; состояние туннеля и доступность интернета остаются разными наблюдениями.

## Acceptance criteria

- [x] Выбор и активный сервер, переключение, ошибка и Retry оформлены в визуальной системе Pencil; незавершённый переход не выглядит успешным подключением. Не добавлены неработающие вкладки или дополнительные функции из макета.
- [x] Визуально проверены переключение, ошибка, Retry и восстановление UI после сворачивания, включая длинные названия и доступность Stop/Retry. Результаты содержат скриншоты без секретов, фреймы-источники и обоснованные отклонения.
- [x] При выборе другого сервера во время активного VPN приложение последовательно останавливает прежнюю сессию и запускает новую, показывая переход и фактически активный профиль.
- [x] Если остановка старой сессии не завершена или завершилась ошибкой, новая не стартует; пользователь получает понятное состояние и возможность повторить остановку.
- [x] Ошибка подключения нового сервера отображается без ложного успеха и без автоматического возврата к старому серверу.
- [x] После терминальной ошибки видны сообщение и «Повторить». Только явная команда пользователя запускает новую попытку, после завершения очистки предыдущей.
- [x] Для неуспешного Connection check при живом туннеле UI сохраняет различие состояний; ручное переподключение сначала корректно останавливает этот туннель.
- [x] Повторные команды, отмена во время переключения и запоздалые события старой сессии не создают второй туннель и не перезаписывают состояние новой. Во время перехода несовместимые команды недоступны или обрабатываются однозначно.
- [x] После сворачивания и повторного открытия UI показан фактический сервер и состояние VPN. Системная остановка или отзыв разрешения отражаются в приложении; сохранённый выбор не подменяет активную сессию.
- [x] Обновление подписки во время соединения не меняет его профиль. Если активный профиль исчез из обновлённого списка, текущая сессия остаётся правильно обозначенной до остановки; для следующего подключения требуется выбор доступного профиля.
- [x] При неудачном обновлении сохраняются прежние профили и активное соединение. Обновление или запуск приложения никогда не инициируют автоматическое подключение.
- [x] Тесты поведения покрывают успешное переключение, отказ остановки, ошибку нового сервера, ручной Retry, события предыдущей сессии, обновление списка и синхронизацию UI.
- [x] В Android Emulator с реальным Xray выполнены переключение между рабочими профилями, контролируемая ошибка подключения, отсутствие автоматического повтора, ручное восстановление, сворачивание UI и окончательное отключение.
- [x] Проверка выбранного профиля учитывает возможность общего выходного IP у нескольких серверов; доказательства и диагностика не содержат приватных URL или ключей.
- [x] Записаны команды, результаты и оставшиеся ограничения полного MVP; неподтверждённые сценарии не обозначены как пройденные.

## Проверка

Использовать уже существующую границу команд и состояния, расширяя проверки на наблюдаемые гонки и ошибки. Проверить полный путь «подписка → профиль A → VPN → профиль B → ошибка → Повторить → отключение» в эмуляторе. Не добавлять авто-восстановление, kill switch или iOS в рамках этой задачи.
